# proyectos-personales
Apps y proyectos personales no fiscales de Daniel Souza.

## Proyectos

### 🌍 Exploradores del Mundo: Banderas
Juego educativo de banderas para primaria (4.º a 6.º). Elige un continente en
cada pregunta, adivina la bandera con pistas progresivas y comodines, y mejora
tu marcador entre rondas.

- ▶️ **Jugar en línea:** https://souzacontador.github.io/proyectos-personales/juego-banderas-exploradores/
- 📁 Código y detalles: [`juego-banderas-exploradores/`](juego-banderas-exploradores/)
